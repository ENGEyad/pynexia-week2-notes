Native Android Notes App implemented with Java and XML. Create, view, edit, search and delete personal notes in a native Android app with a custom RecyclerView adapter and SQLite persistence.

Entry models, a custom ListAdapter, DiffUtil and ViewHolder render the note list. Stable database IDs keep records distinct even when titles match. SQLiteOpenHelper stores title and full text. A single background executor serializes reads and writes. Viewing opens the complete note; deletion requires confirmation. Title: 1-120 trimmed characters. Note body: required, up to 10,000 characters. Search is literal and case-insensitive. Editor drafts and in-flight save state survive Activity recreation.

Run: open the source folder in Android Studio, sync Gradle, and run notes on Android 8.0/API 26 or later (compile/target SDK 35).

Validation: 4 JVM tests and 3 device tests passed on a Pixel 8 emulator, Android 17/API 37. Lint: zero errors; 18 warnings documented without suppression.

Local storage only. No cloud sync or encryption. Clearing app data/uninstalling removes notes. Duplicate titles are allowed; records have distinct IDs.

Hosted URL: project showcase with actual screenshots and downloads, not a browser emulator. The ZIP contains source, Gradle wrapper, debug APK, screenshots, verification and a bilingual PDF report.
